# ניהול לידים

כלי פנימי לניהול לידים ומעקב חזרות, בנוי ב-Next.js ומיועד לדיפלוי על Vercel.

## מה יש כאן

- מסך התחברות עם סיסמה אחת (`APP_PASSWORD`), עוגיית התחברות ל-90 יום. כל שאר האתר חסום ב-`proxy.ts` עד כניסה.
- טבלת `leads` ב-Postgres (נוצרת אוטומטית באזעקה הראשונה - אין צורך בהרצת מיגרציה ידנית).
- מסך ראשי: "מי שצריך לחזור אליו היום" (כולל איחורים, מסומן באדום), תיבת סטטיסטיקה, וטבלת כל הלידים עם חיפוש/סינון/מיון ועריכה מהירה של תאריך מעקב וסטטוס.
- הוספה/עריכה/מחיקה של לידים.

כל הפעולות (התחברות, יצירה/עריכה/מחיקה, עדכון מהיר) ממומשות כ-Server Actions של Next.js — אין צורך ב-API routes נפרדים.

## פריסה ל-Vercel

1. **דחיפת הקוד ל-GitHub** (או חיבור ישיר עם `vercel` CLI שכבר מותקן במחשב).
2. **יצירת פרויקט ב-Vercel**: בלוח הבקרה → Add New → Project → יבוא הריפו.
3. **חיבור מסד נתונים**: בתוך הפרויקט → Storage → Create Database → Postgres. Vercel תחבר אותו אוטומטית ותזריק את משתני הסביבה (`DATABASE_URL` וכו') לכל הסביבות (Production/Preview/Development).
4. **הגדרת הסיסמה**: Settings → Environment Variables → הוסיפו `APP_PASSWORD` עם הסיסמה שתרצו (לכל הסביבות).
5. **Deploy**.

## פיתוח מקומי

```bash
npm install
vercel link          # פעם אחת - מקשר את התיקייה לפרויקט ב-Vercel
vercel env pull       # מושך את משתני הסביבה (כולל חיבור למסד) לקובץ .env.local
npm run dev
```

## מבנה

- `lib/db.ts` - שכבת גישה למסד הנתונים (postgres.js), כולל יצירת הטבלה אוטומטית.
- `lib/auth.ts` - בדיקת סיסמה וחתימת/אימות עוגיית ההתחברות.
- `lib/actions.ts` - כל ה-Server Actions (התחברות, התנתקות, CRUD לידים).
- `proxy.ts` - שומר על כל האתר מאחורי התחברות (זהו ה-middleware של Next.js 16, שהוחלף בשם `proxy`).
- `app/page.tsx` - המסך הראשי.
- `app/login/page.tsx` - מסך ההתחברות.
